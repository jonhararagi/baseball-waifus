# Baseball Waifus · Guía visual inicial

Esta imagen es la **guía visual de dirección artística inicial** de Baseball Waifus.

![Baseball Waifus visual guide](../assets/art_reference/baseball_waifus_visual_guide.svg)

## Uso

La lámina sirve para mantener una identidad visual común mientras se desarrollan los personajes:

- anime deportivo;
- personajes femeninos adultos;
- variedad de siluetas, cabello, colores y presencia visual;
- uniformes de béisbol;
- presentación colorida y orientada a colección;
- coherencia de roster antes de producir retratos individuales.

## Regla de continuidad

La imagen es **referencia visual**, no fuente de verdad de gameplay ni de nombres.

La fuente de verdad del roster sigue siendo:

`game/characters/character_archetypes.json`

Los nombres, rarezas, estadísticas, posiciones, elementos y especializaciones se toman del catálogo. Los detalles que aparezcan espontáneamente en la lámina no crean canon por sí mismos.

Las variantes permitidas siguen siendo únicamente:

1. color de cabello;
2. peinado;
3. escala corporal global.

## Licencia y procedencia

La imagen fue generada para el proyecto como concept art de referencia. No se incorporó código ni arte de terceros al repositorio.

Antes de usar la referencia como arte final redistribuible, se revisarán las condiciones de uso del proveedor/modelo de generación correspondiente.

## Evolución

Esta lámina se considera el **primer ancla visual del estilo Baseball Waifus**. Las futuras hojas de roster y retratos individuales deben conservar su lenguaje general, pero pueden mejorar anatomía, poses, uniformes y consistencia sin quedar atados a personajes accidentales que aparezcan en la referencia.


## Canon de continuidad

La dirección visual de esta guía queda consolidada junto con el roster y los assets generados en [`docs/canon/character-art-canon-v1.md`](canon/character-art-canon-v1.md). La guía sigue siendo referencia de estilo y no reemplaza el catálogo JSON.
