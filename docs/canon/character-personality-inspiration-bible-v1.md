# Mini Biblia de personalidad e inspiración · Baseball Waifus v1

**Estado:** CANÓNICA como herramienta de diseño, no como canon de personajes asignados.  
**Fecha:** 2026-09-21

## Propósito

Esta biblia permite estudiar personalidades y actitudes de anime/manga populares para crear personajes originales de Baseball Waifus sin copiar personajes concretos.

La referencia sirve para extraer funciones dramáticas y comportamientos, no identidades.

## Regla principal: inspiración ≠ plantilla

Se puede estudiar:
- actitud;
- forma de competir;
- forma de reaccionar bajo presión;
- manera de relacionarse;
- defecto;
- virtud;
- ritmo social;
- conflicto interno.

No se debe copiar:
- nombre;
- diseño;
- combinación característica de pelo/ojos;
- historia de origen;
- trauma concreto;
- poder;
- arma;
- uniforme;
- frase icónica;
- relación con otro personaje;
- escena reconocible;
- arco narrativo;
- personalidad completa de un personaje existente.

## Conversión a Baseball Waifus

Una referencia debe transformarse en una combinación nueva de ejes.

Ejemplo:

curiosidad + competitividad moderada + humor seco + miedo a equivocarse

es válido como semilla.

“personaje X pero con uniforme de béisbol” no es válido.

## Banco de ejes

Cada personaje nuevo puede recibir de 3 a 5 ejes:

- energía social;
- competitividad;
- paciencia;
- curiosidad;
- disciplina;
- espontaneidad;
- prudencia;
- orgullo;
- empatía;
- pragmatismo;
- sentido del humor;
- expresividad;
- tolerancia al fracaso;
- liderazgo;
- cooperación;
- independencia;
- necesidad de reconocimiento;
- curiosidad táctica;
- confianza;
- autocontrol.

## Regla S/SR

Las personajes S/SR pueden recibir personalidad más marcada y memorable, pero la rareza no determina personalidad.

Una SR puede ser tranquila, caótica, protectora, sarcástica o tímida. Una S/SSR puede tener una personalidad cotidiana aparentemente sencilla y aun así ser interesante.

## Guardia contra coincidencias

Antes de asignar una inspiración a un personaje existente, comprobar:

1. nombre y apellido;
2. pelo;
3. ojos;
4. color dominante;
5. elemento;
6. posición;
7. especialidad;
8. rasgos de personalidad;
9. historia de origen;
10. símbolos.

Si la combinación se parece demasiado a una referencia conocida, cambiar primero la personalidad o historia, no solo el color.

## Regla de no contaminación del canon

Este archivo no modifica character_archetypes.json.

La personalidad definitiva de una personaje solamente se vuelve canon cuando exista una entrada específica de personaje que la registre.
