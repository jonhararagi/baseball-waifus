# BaseWarriors: Meta-Strike · Universe Terminology

Este documento fija el vocabulario canónico inicial del universo. Es una referencia terminológica, no una lore bible completa.

## Sport terminology

Estas palabras siguen siendo el vocabulario deportivo normal y no deben ser reemplazadas automáticamente:

- BATTER
- PITCH
- CATCHER
- OUTFIELD
- HOME RUN
- DIAMOND
- TIMING

La terminología del universo se construye alrededor de este lenguaje deportivo.

## Universe terminology

### KYTOS
Enemigos o parásitos del universo.

### LYSIS
Proceso de destrucción o descomposición celular. Puede utilizarse para describir zonas o efectos de corrupción.

### KYTOKINESIS
Fenómeno relacionado con la proliferación o división de Kytos.

### LIFE CORE
Núcleo energético de las jugadoras.

### KINETIC ENERGY
Lenguaje energético que conecta movimiento, combate y béisbol.

### KINETIC HOME RUN
Contraataque perfecto en el que la energía enemiga se convierte en una devolución ofensiva.

### G-BAT
Bate tecnológico destinado a canalizar fuerza y aceleración.

### MACH BALL
Lanzamiento o proyectil de velocidad extrema.

### INERTIA MITT
Guante especializado en absorber o gestionar energía cinética.

## Usage rules

La terminología científica complementa al béisbol. No debe saturar los diálogos ni convertirse en jerga obligatoria.

Usar cada término cuando aporte significado contextual:

- Kytos para amenazas o enemigos.
- Life Core para la energía propia de una jugadora.
- Kinetic Energy para el lenguaje energético del movimiento y el combate.
- Kinetic Home Run para el fenómeno o técnica correspondiente.
- Lysis para corrupción, destrucción o descomposición.
- G-Bat para la tecnología del bate.
- Mach Ball para lanzamientos de velocidad extrema.
- Inertia Mitt para la tecnología defensiva de absorción o gestión de energía.

No introducir definiciones adicionales como hechos canónicos hasta que exista una decisión de diseño explícita.
